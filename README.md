# Holiday Cost Calculator

## Description
A Python program (holiday.py) that calculates the total cost of a user's holiday—including flight tickets, hotel accommodation, and car rental—based on their chosen destination city, number of nights, and rental days.

## How to Run
1. Please make sure that you have Python installed on your system.
2. Open your terminal or command prompt in the project directory.
3. Run the script using the following command:
   `ash
   python holiday.py
City Flight: Choose your destination city from the available options.

Num Nights: Enter the number of nights you will stay at the hotel.

Rental Days: Enter the number of days you will rent a car.
